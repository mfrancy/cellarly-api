# 🍷 Cellarly API

REST API for Cellarly, a personal wine journal application.

The API is responsible for managing wines, tasting logs, collections, reviews, and user data.

## Tech Stack

- ASP.NET Core
- C#
- Entity Framework Core
- PostgreSQL
- Swagger / OpenAPI

## Features

- Wine management
- RESTful endpoints
- Data validation
- OpenAPI documentation
- Database integration

## Getting Started

### Requirements

- .NET 9 SDK
- PostgreSQL

### Running the project

```bash
dotnet restore
dotnet run
```

Swagger:

```
https://localhost:xxxx/swagger
```
